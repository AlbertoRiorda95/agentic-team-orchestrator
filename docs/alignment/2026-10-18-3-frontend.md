## What changed
The npm workspaces, `packages/tokens`, `packages/api-client`, `packages/shared`,
`apps/web` and `apps/mobile` exist, with the status page on both apps, following
`docs/design/foundations.md`. This entry lists what designer should review and
what devops wires into the Makefile, `.env.example` and CI.

## What the others relied on (before → after)
Design tokens (designer): the tables of the design-system skill, plus these
additions the spec did not list, needed by the status page:
- `layout.narrow` = 480 px (as specified), exposed as `max-w-narrow`.
- `layout.touch` = 44 px, exposed as `min-h-touch` / `min-w-touch` (touch targets).
- `primary-foreground` = `#FFFFFF` (text on `primary`, from the design-system table
  "filled primary buttons, with #FFFFFF text") and `accent-violet-text` = `#8B6BFB`
  ("as text use"), both promoted to named colors.
- `motion.fast` = 120 ms and `motion.base` = 200 ms (the spec only says "under 200 ms").
- `fontFaces`: each weight is its own family on mobile (`Inter_500Medium`...), exposed
  as `font-native-sans`, `font-native-sans-medium`... in the shared preset; web uses
  `font-sans` and `font-weight`.
- Border color: no token exists for borders. The secondary button and the check
  badges use `fg-subtle` (5.6:1 on `bg`) as border, to keep 3:1 for UI borders.
  Designer to confirm or define a border token.

Brand asset on the page (designer): `logo.png` has a light background and the
wordmark, so it cannot sit on `bg`. The 48 px logo uses `app-icon.png` instead,
cropped around the robot mark with CSS (`object-cover` + `scale-150`); the exported
file has a lot of padding. A square, transparent mark would be cleaner.

Commands (devops): from the repo root, `npm ci`, `npm run lint`
(`eslint . && prettier --check .`), `npm run typecheck` (`tsc --noEmit` in every
workspace), `npm test` (runs `vitest` for web and packages, `jest` for mobile; the
tokens workspace also checks that its generated files are up to date), `npm run build`
(web bundle, `apps/web/dist`), `npm run build:mobile` (`expo export` for Android and
web, `apps/mobile/dist`, needs no native toolchain), `npm run gen:api` (regenerates
`packages/api-client/src/schema.d.ts`; CI drift check: run it and `git diff
--exit-code packages/api-client`), `npm run gen:tokens` (regenerates
`packages/tokens/tokens.css`, `tailwind-preset.cjs`, and copies the brand assets from
`docs/design/brand/`; CI drift check: `npm run gen:check -w packages/tokens`).

Ports and environment (devops): web dev server 5173, with `/api` proxied to
`VITE_API_PROXY_TARGET` (default `http://localhost:8000`, read from the environment or
a root `.env`); Expo dev server 8081; mobile reads `EXPO_PUBLIC_API_URL` (default
`http://localhost:8000/api/v1`). No new variables beyond the spec.
