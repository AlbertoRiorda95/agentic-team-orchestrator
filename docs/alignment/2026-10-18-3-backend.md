## What changed
`docs/api/openapi.yaml` is now the FastAPI export (the v0.1 hand-written
contract moved to `docs/api/openapi-v0.1-design.yaml`), and `backend/` exists
with the interfaces devops wires into the Makefile, the image and compose.
Everything follows `docs/design/foundations.md`; this entry lists the concrete
names other roles now rely on.

## What the others relied on (before → after)
Contract (frontend, `npm run gen:api`):
- `openapi.yaml`: v0.1 with 76 operations → exactly `GET /health`
  (`operationId: health`) and `GET /health/ready` (`operationId: readiness`),
  server `http://localhost:8000/api/v1`, `info.version` 0.1.0, no security.
- `Health`: `status` (required, `$ref HealthStatus`: ok | degraded | down),
  `checks` (optional map of `$ref CheckStatus`: ok | failed), `version`
  (optional string, e.g. `0.1.0+abc1234`; always sent by the API). Optional
  fields are omitted, never `null`. `HealthStatus` and `CheckStatus` are named
  schemas now (inline enums in v0.1).
- `/health/ready` answers `503` with the same `Health` body when the database
  check fails or takes more than 2 s; `Content-Type: application/json`.
- Every error is `application/problem+json`: `{type, title, status}` plus
  optional `detail` and, for 422, `errors[]` of `{field, message}`
  (`field` is the dotted location, e.g. `body.name`, `query.limit`).

Commands and runtime (devops: Makefile, `backend/Dockerfile`, compose, CI):
- Install: `uv sync --directory backend` (add `--frozen` in CI and the image).
  The project is a package (`devorchestrator-api`, build backend `uv_build`):
  it must be installed, i.e. do NOT use `--no-install-project` for the final
  sync, because the API reads its version from the package metadata.
- `make openapi` → `uv run --directory backend python scripts/export_openapi.py`
  (writes `docs/api/openapi.yaml`; `--check` exits 1 when it is out of date).
- Lint: `uv run --directory backend ruff check .` and
  `uv run --directory backend ruff format --check .`; type check:
  `uv run --directory backend mypy`; tests: `uv run --directory backend pytest`.
- Migrations: `alembic upgrade head`, run from `backend/` (uses `alembic.ini`
  there), URL from `DATABASE_URL`.
- Server: `fastapi run` from `backend/` (entrypoint `app.main:app` in
  `pyproject.toml`), port 8000. Healthcheck path `/api/v1/health`.
- `DATABASE_URL` has no default in the code: the API refuses to start when it
  is unset or blank. The local default from the spec goes in `.env.example`.
  `CORS_ORIGINS` (comma separated, default `http://localhost:8081`) and
  `GIT_SHA` (optional) as in the spec.
- Tests: the database tests (readiness ok, migrations) need `DATABASE_URL`
  pointing at a real PostgreSQL and are skipped without it; CI's
  `build-test` job already sets it. The migrations test leaves the database
  at head.
- Interactive docs at `/api/v1/docs` (Swagger UI assets come from FastAPI's
  default CDN; dev-only use).
